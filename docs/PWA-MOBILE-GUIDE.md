# PWA Mobile-first v2.0.0

## Sasaran
Pengguna utama mobile adalah guru dan wali. Informasi penting harus muncul lebih dahulu dan tindakan rutin harus sedikit langkah.

## Perubahan
- Sidebar menggunakan transform penuh sehingga tidak menyisakan strip ketika tertutup.
- Bottom navigation 5 item berdasarkan peran.
- Form dan tombol utama berukuran besar.
- Safe-area iOS/Android diperhitungkan.
- Konten diberi ruang bawah agar tidak tertutup bottom navigation.
- Sidebar tetap tersedia sebagai menu lengkap, tetapi bukan navigasi utama di ponsel.

## Pengujian wajib
Chrome Android, PWA standalone, Safari iPhone bila tersedia, viewport 360/390/430/768, mode portrait, dan keyboard terbuka pada form.
