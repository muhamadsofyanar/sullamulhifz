# Contoh User Flow

## Admin

1. Login.
2. Melihat dashboard lembaga.
3. Memilih Tahun Ajaran 2026/2027.
4. Memeriksa kelas, guru, santri, dan wali.
5. Mengelola jadwal dan pengumuman.
6. Memantau pertemuan serta catatan yang belum lengkap.
7. Menerbitkan laporan.
8. Mengelola profil lembaga.

## Guru Tahsīn

1. Login.
2. Melihat kelas yang diampu.
3. Membuka pertemuan.
4. Mengisi absensi.
5. Mengisi penilaian tahsīn secara cepat.
6. Menambahkan catatan individual bila diperlukan.
7. Menutup pertemuan.
8. Menjawab buku penghubung.

## Guru Tahfizh — Sofyan

1. Login.
2. Memilih Tahfizh A atau Tahfizh B.
3. Membuka pertemuan.
4. Melihat target setiap santri.
5. Mencatat hafalan baru atau murāja'ah.
6. Menentukan status lanjut, ulang, atau penguatan.
7. Memberikan tugas rumah personal.
8. Menutup pertemuan.

## Wali

1. Login.
2. Memilih anak bila memiliki lebih dari satu anak.
3. Melihat jadwal dan pengumuman.
4. Melihat perkembangan tahsīn, tahfizh, murāja'ah, dan kehadiran.
5. Melihat tugas rumah.
6. Mengirim respons atau bukti opsional.
7. Menggunakan buku penghubung secara privat.
8. Membaca Pembinaan Jumat.
