# Quran Player v2 — Senior-friendly

## Default sederhana
Pengguna hanya perlu memilih qari, jenis latihan/surah, dan jumlah pengulangan. Pengaturan jeda, kecepatan, serta pola repeat berada di bagian **Pengaturan lanjutan**.

## Qari
- Mahmoud Khalil Al-Husary: pilihan utama tahfizh.
- Muhammad Siddiq Al-Minshawi: pilihan murāja‘ah dan tadabbur.

## Mode
Satu ayat, beberapa ayat, satu surah, satu halaman Mushaf, satu rubu’ Juz 30, preset, dan target guru.

## Repeat
1×, 3×, 5×, 10×, 20×, atau tanpa batas; per ayat atau seluruh pilihan.

## Prinsip penggunaan
Murattal membantu latihan mandiri. Talaqqi dan koreksi guru tetap menjadi rujukan utama.
