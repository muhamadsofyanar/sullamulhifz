# Qari Tahfizh v1.6.1

## Qari utama — Mahmoud Khalil Al-Husary

Peran dalam Sullamul Ḥifẓ:

- talaqqi;
- ketelitian makhraj dan tajwid;
- penguatan hafalan baru;
- latihan ayat berulang;
- standar pembanding bacaan santri.

Sumber audio menggunakan murattal Hafs dari Asim pada MP3Quran dengan timing API read `118`.

## Qari pilihan — Muhammad Siddiq Al-Minshawi

Peran dalam Sullamul Ḥifẓ:

- murajaah;
- menyimak dengan tempo tenang;
- tadabbur;
- penguatan hubungan emosional dengan bacaan Al-Qur'an.

Sumber audio menggunakan murattal Hafs dari Asim pada MP3Quran dengan timing API read `112`.

## Aturan penggunaan

- Guru tetap menjadi rujukan utama koreksi bacaan.
- Murattal membantu latihan, bukan menggantikan talaqqi.
- Qari dapat dipilih untuk ayat, rentang, surah, halaman, rubu', target, dan preset.
- Al-Husary menjadi pilihan awal aplikasi.
- Pengguna tetap dapat berpindah ke Al-Minshawi kapan saja.
