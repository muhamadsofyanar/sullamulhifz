# Brand Guide Sullamul Ḥifẓ — v1.2.0

## Identitas utama

- **Nama:** Sullamul Ḥifẓ
- **Tagline:** Bukan Sekadar Hafal, Tapi KUAT
- **Karakter:** pembimbing, hangat, terpercaya, bertumbuh, istiqamah
- **Makna simbol:** tunas emas melambangkan pertumbuhan dan tujuan luhur; dua daun hijau melambangkan penjagaan, keluarga, dan perjalanan yang dibimbing.

## Palet warna

| Nama | Hex | Pemakaian |
|---|---|---|
| Deep Emerald | `#004B3F` | navigasi, tombol utama, judul penting |
| Emerald | `#0F624D` | hover, elemen aktif, grafik |
| Warm Gold | `#D3A13A` | aksen, pencapaian, titik fokus |
| Ivory | `#F8F4EA` | latar utama dan ruang bernapas |
| Ink | `#182B24` | teks utama |
| Muted | `#66776F` | teks sekunder |

## Penggunaan logo

- `public/brand/logo-horizontal.svg`: login, halaman publik, dokumen digital.
- `public/brand/logo-horizontal-light.svg`: sidebar atau latar hijau gelap.
- `public/brand/logo-mark.svg`: favicon, avatar aplikasi, ikon kecil.
- Jangan memutar, memipihkan, menambah outline, atau mengubah warna logo di luar palet resmi.

## Pemetaan ikon aplikasi

- Beranda → Home
- Santri → Student
- Guru → Teacher
- Akademik → Plan
- Konten & Pembinaan → Guidance
- Laporan → Progress
- Buku Penghubung → Discussion
- Pengumuman → Community
- Pembinaan Jumat → Values
- Profil → Profile
- Jadwal → Schedule
- Tugas → Lesson/Plan

Ikon menggunakan garis hijau/putih dengan aksen emas. Ikon harus selalu ditemani label teks pada navigasi utama agar tetap jelas dan aksesibel.

## Tipografi

- Wordmark: serif elegan, menggunakan fallback `Georgia`/`Times New Roman` dalam aset SVG.
- Antarmuka: system sans-serif untuk kecepatan dan keterbacaan.
- Gunakan serif hanya untuk identitas dan judul emosional, bukan tabel atau form.

## Prinsip tampilan

1. Hangat, tidak ramai.
2. Aksen emas hanya untuk fokus penting.
3. Latar ivory dan kartu putih menjaga kenyamanan membaca.
4. Ikon memperkuat navigasi, tidak menggantikan label.
5. Semua halaman harus tetap nyaman di desktop dan ponsel.
