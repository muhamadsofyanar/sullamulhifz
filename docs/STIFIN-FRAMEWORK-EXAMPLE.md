# Contoh Kerangka STIFIn

## Status awal

Semua santri menggunakan:

**STIFIn: Belum Dites**

STIFIn belum menjadi fitur inti dan tidak wajib diisi.

## Pilihan profil bila sudah ada hasil resmi

- Sensing
- Thinking
- Intuiting
- Feeling
- Insting

## Aturan penggunaan

STIFIn hanya menjadi informasi tambahan, tidak menentukan kelas, marhalah, nilai, atau ranking, dan tidak menggantikan observasi guru.

## Contoh profil

| Field | Contoh |
|---|---|
| Status tes | Belum Dites |
| Profil | Kosong |
| Tanggal tes | Kosong |
| Sumber hasil | Kosong |
| Catatan guru | Lebih mudah mengikuti materi melalui contoh dan pengulangan |
| Metode yang dicoba | Mendengar audio, membaca berulang, talaqqi |
| Respons | Audio dan talaqqi membantu |
| Kesimpulan | Catatan observasi sementara, bukan diagnosis |

## Contoh bank metode

- membaca berulang;
- mendengarkan dan menirukan audio;
- menulis ayat;
- menyusun potongan kata;
- menghafal sambil bergerak;
- menggambar hubungan makna;
- membuat peta konsep;
- bercerita;
- mengajarkan kembali kepada orang tua;
- talaqqi bersama pendamping.
