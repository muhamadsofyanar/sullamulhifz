# Panduan Wali v1.9.0

1. Masuk melalui `app.sullamulhifz.or.id`.
2. Pilih anak pada dashboard.
3. Lihat ringkasan hari ini, target, kehadiran, Tahsīn, Tahfizh, Murāja‘ah, dan rapor.
4. Gunakan tombol Latihan Al-Qur’an untuk mengulang bacaan sesuai arahan guru.
5. Pada tugas, gunakan checklist atau catatan bila unggahan tidak diperlukan.
6. Gunakan Buku Penghubung untuk komunikasi privat.
7. Jangan membandingkan jumlah atau kecepatan hafalan anak dengan santri lain.
