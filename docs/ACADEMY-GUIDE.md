# Panduan Sullamul Ḥifẓ Academy

## Struktur awal
### Parent Academy
Materi awal meliputi rumah dekat Al-Qur’an, mendampingi tahfizh tanpa tekanan, murāja‘ah, perkembangan anak, komunikasi positif, kehilangan ritme, adab, dan keteladanan.

### Teacher Academy
Orientasi guru tentang Minimum Meaningful Documentation, Human Before Data, No Ranking Culture, alur pertemuan, target realistis, dan komunikasi dengan keluarga.

## Alur wali
Beranda → Parent Academy → pilih program → buka materi → tandai selesai. Rekomendasi guru tampil sebagai prioritas dan juga terhubung dengan profil anak.

## Alur guru
Academy & Keluarga → pilih santri yang diampu → pilih satu materi Parent Academy → tulis pesan singkat → kirim rekomendasi.

## Alur admin
Kelola Academy → program → modul → materi. Materi dapat berupa artikel, video, audio, PDF/link, aktivitas, atau checklist.

## Batasan v2.0.0
Belum mencakup pembayaran kompleks, sertifikat kompleks, video conference, marketplace, atau LMS tingkat lanjut. Academy v2.0.0 berfokus pada komunikasi pembelajaran keluarga.
