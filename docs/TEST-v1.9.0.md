# Checklist Pengujian v1.9.0

## Admin

- Dashboard tetap menampilkan 88 santri, 88 wali, 4 guru, 6 kelas, dan 2 kelompok.
- Profil lembaga dapat disimpan.
- Academic Core dan Pustaka Qur’an terbuka.
- Menu Siap Launch terbuka dan status checklist dapat disimpan.
- Ringkasan bulanan serta ekspor tugas dapat diunduh.
- Rapor dapat dibuat, diperbarui, diterbitkan, dan dicetak.

## Guru

- Workspace Operasional Hari Ini terbuka.
- Pertemuan dapat dibuat.
- Semua hadir dapat dipilih dan disimpan.
- Tahsīn, Tahfizh, dan Murāja‘ah dapat dicatat.
- Target Tahfizh berubah sesuai hasil setoran.
- Pertemuan tidak dapat ditutup sebelum absensi lengkap.
- Ringkasan wali hanya terlihat setelah dipublikasikan.
- Tugas audio dapat dibuat dengan Al-Husary atau Al-Minshawi.

## Wali

- Hanya dapat melihat anak yang terhubung.
- Ringkasan hari ini dan bulanan tampil.
- Target dapat membuka Latihan Al-Qur’an.
- Tugas dapat menggunakan checklist tanpa wajib unggah.
- Buku Penghubung tetap privat.
- Rapor terbit dapat dilihat.

## PWA dan keamanan

- Instalasi PWA berfungsi.
- Halaman offline muncul saat koneksi terputus.
- Halaman 403, 404, 419, 429, 500, dan 503 tampil ramah.
- Riwayat login muncul pada profil dan menu Siap Launch.
- Role tidak dapat membuka halaman role lain.
