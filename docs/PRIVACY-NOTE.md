# Catatan Privasi Repository

Repository publik tidak boleh memuat:

- daftar lengkap nama anak;
- tanggal lahir anak;
- alamat rumah;
- nomor WhatsApp wali;
- email akun wali;
- password;
- `APP_KEY`;
- `DB_URL`;
- `INITIAL_TPA_DATA_KEY`;
- foto atau video anak tanpa mekanisme izin;
- hasil STIFIn individual;
- catatan perkembangan individual.

Dokumentasi publik memakai nama fiktif. Data nyata disimpan di database dan secret environment, bukan di source GitHub.
