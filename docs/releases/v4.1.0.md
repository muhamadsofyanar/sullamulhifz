# v4.1.0 — WhatsApp & Email Completion

Rilis ini menyelesaikan fondasi komunikasi eksternal yang sejak v2.3 hanya berupa koneksi nonaktif. Admin kini dapat memilih provider, memeriksa kesiapan environment, mengirim tes, mengatur event, menyunting template, melihat riwayat, dan mengirim ulang kegagalan.

WhatsApp mendukung StarSender sesuai endpoint `POST /api/send` dan provider generik/OneSender yang nama field, format JSON/form, header, dan lokasi tokennya dapat diatur melalui environment. Email mendukung SMTP standar dan Mailketing API. Integrasi Buku Penghubung hanya mengirim pemberitahuan serta tautan portal; isi percakapan privat tidak disalin ke WhatsApp/email.

Keamanan: API key tidak pernah disimpan di database, isi delivery memakai encrypted cast Laravel, webhook membutuhkan secret, alamat dimasking di UI, dan notifikasi otomatis memiliki idempotency key.

Kanal tetap nonaktif setelah migration. Aktivasi harus dilakukan manual setelah tes pada kontak admin berhasil.
