# v4.5.0 — Personal 2.0: Setiap Orang, Setiap Cita

`@phase 4.5`

Rilis ini menempelkan konteks usia, minat, cita-cita, dan tujuan Qur’ani pada Ruang Personal yang sudah ada. Tidak ada aplikasi atau modul profesi baru. Cita-cita membantu pengguna menghubungkan perjalanan nyata dengan nilai Qur’ani, tanpa ranking atau klaim penilaian kemampuan.

## Fitur utama

- kelompok usia tanpa menyimpan tanggal lahir;
- katalog minat dan cita-cita bebas;
- empat jalur: mandiri, bersama orang tua/wali, ustadz privat, atau lembaga;
- tujuan Qur’ani di Beranda dan Perjalanan Saya;
- portofolio privat tanpa skor, ranking, atau perbandingan;
- guardrail pengguna di bawah 18 tahun dan Community tetap opt-in;
- regresi dashboard Guru/Wali untuk konteks multi-workspace.

## Status

Implementasi source siap diperiksa. Fase 4 belum berstatus verified sampai GitHub Actions, migration produksi, verifier, dan smoke test akun nyata lulus.
