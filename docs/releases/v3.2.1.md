# Sullamul Ḥifẓ v3.2.1 — Official Bank Transfer Configuration

Patch ini melengkapi payment readiness Fase 10 dengan identitas rekening transfer resmi tanpa mengaktifkan pembayaran secara otomatis.

## Rekening resmi

- Bank: **BSI (Bank Syariah Indonesia)**
- Nomor rekening: **7350451147**
- Nama rekening: **YYS INSAN QURAN MADANI**

## Implementasi

Konfigurasi rekening tersedia melalui environment dengan default resmi di source. `PaymentLedgerService` dapat membuat transaksi transfer manual dan menyimpan snapshot rekening tujuan di metadata transaksi, sehingga histori transaksi tidak bergantung pada perubahan konfigurasi di masa depan.

## Keamanan aktivasi

Feature flag pembayaran tetap OFF sampai alur UI, verifikasi pembayaran, otorisasi admin, dan pengujian end-to-end siap. Tidak ada migration baru pada v3.2.1.
