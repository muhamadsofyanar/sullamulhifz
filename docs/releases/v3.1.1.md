# v3.1.1 — Guided Quran Learning Recovery

Patch recovery untuk kandidat Guided Quran Learning setelah migration v3.1.0 berhenti sebelum tercatat selesai.

Perubahan utama adalah pemberian nama eksplisit yang pendek pada foreign key `quran_guided_submission_reviews`, sehingga nama constraint tidak melewati batas identifier MySQL. Migration tetap menggunakan ID `002200` karena production menunjukkan status `Pending`.

Patch ini tidak menghapus atau mengubah data Personal v3.0.0. Setelah deploy, migration, verifier Guided Quran, dan smoke test end-to-end wajib dibuktikan di production.
