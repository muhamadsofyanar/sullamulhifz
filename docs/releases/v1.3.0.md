# Release v1.3.0 — Public Website

## Tujuan

Memisahkan wajah publik Sullamul Ḥifẓ dari portal operasional tanpa memecah basis kode atau mengubah database.

## Fitur

- beranda publik;
- halaman Tentang, Program, TPA, Academy, Artikel, Kontak, dan Privasi;
- navigasi publik responsif;
- metadata SEO, Open Graph, robots, dan sitemap;
- host-aware root untuk `app.sullamulhifz.or.id`;
- tombol kembali ke website pada halaman login;
- service worker versi baru yang tidak menyajikan cache navigasi lama;
- paket persiapan DNS dan subdomain.

## Dampak database

Tidak ada migration baru dan tidak ada seeding ulang.

## Privasi

Website publik tidak memuat nama santri, akun wali, laporan pembelajaran, media anak, atau environment secret.
