# Sullamul Ḥifẓ v1.4.5 — Portal Domain Separation

- **Tanggal:** 6 Agustus 2026
- **Tipe:** patch
- **Status:** release candidate untuk deployment produksi

## Tujuan

Memisahkan website publik dan portal operasional tanpa memecah aplikasi atau database.

## Perubahan

- middleware pemisahan hostname;
- canonical redirect `www` ke non-`www`;
- redirect rute autentikasi dan dashboard ke subdomain `app`;
- redirect halaman publik yang dibuka dari subdomain `app` ke domain utama;
- domain lama tetap tersedia selama masa transisi;
- pengujian fitur dan smoke test domain;
- dokumentasi Coolify dan rollback.

## Dampak database

Tidak ada.

## Environment Variables

Lihat `UPGRADE-V1.4.5.md`.

## Keamanan

- cookie sesi tetap host-only dengan `SESSION_DOMAIN=null`;
- HTTPS wajib;
- Cloudflare menggunakan Full (Strict);
- tidak ada rahasia baru di repository.
