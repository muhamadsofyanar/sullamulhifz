# v3.0.0 — Public Self-Registration + Personal Mode

Rilis kandidat yang membuka Sullamul Hifz kepada masyarakat umum untuk penggunaan mandiri tanpa harus terdaftar pada lembaga.

## Nilai utama

- pendaftaran akun publik dengan rate limit dan standar kata sandi kuat;
- private personal workspace per pengguna;
- onboarding fokus dan ritme harian;
- jurnal hafalan, Murāja‘ah, tilawah, dan refleksi;
- target otomatis berbasis ayat, menit, hari aktif, atau sesi;
- statistik 7 hari dan streak;
- arahan harian berbasis aktivitas nyata tanpa STIFIn;
- isolasi ownership dan navigasi khusus Personal;
- jalur pendaftaran TPA lama tetap dipertahankan.

Migration bersifat additive terhadap v2.9.0. Rilis harus melewati GitHub Actions, verifier `sullam:verify-personal-mode`, smoke test pendaftaran, dan uji isolasi dua akun sebelum dinyatakan stabil.
