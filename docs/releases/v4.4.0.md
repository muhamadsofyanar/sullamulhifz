# v4.4.0 — Universal Product, Identity Core & Multi-tenant Foundation

`@phase 4.2` · `@phase 4.3` · `@phase 4.4`

Rilis ini menggabungkan tiga fase yang berurutan agar reposisi produk tidak berhenti di Home, tetapi langsung memiliki fondasi akun dan lembaga yang sesuai.

## Fase 4.2

- Home menjelaskan Sullamul Ḥifẓ, empat jalur pengguna, dan lima pola hubungan.
- TPA Al-Insyirah menjadi contoh implementasi.
- Navigasi publik berpusat pada Solusi, Fitur, Academy, Artikel, Harga, dan Tentang.

## Fase 4.3

- Satu akun dapat memiliki beberapa membership workspace.
- Session memilih workspace aktif tanpa menghapus fallback lembaga lama.
- Hubungan personal–ustadz dan orang tua–anak memerlukan persetujuan.
- Invitation ledger tersedia untuk fase undangan berikutnya.

## Fase 4.4

- Mendukung TPA, rumah tahfiz, pesantren, SD, SMP, SMA, kampus, dan komunitas.
- Istilah peserta, pengajar, dan wali dapat disesuaikan.
- Warna utama/aksen diterapkan pada workspace aktif dan profil guru/wali mengikuti konteks tersebut.
- Pendaftaran lembaga membuat ruang onboarding dan owner membership.
- Superadmin dapat mengaktifkan, menolak, atau menangguhkan ruang.
- Modul operasional tertutup sampai status ruang aktif.

## Traceability

Seluruh file runtime dan test rilis ini tercatat di `PHASE-MANIFEST.json` dan divalidasi oleh `scripts/check-phase-manifest.py` pada GitHub Actions.
