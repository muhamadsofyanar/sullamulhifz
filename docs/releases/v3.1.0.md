# v3.1.0 — Guided Quran Learning

Rilis ini menjadikan Personal sebagai pintu masuk mandiri, bukan sinonim “belajar sendirian”. Pengguna dapat tetap memakai target/jurnal privat atau secara sadar mengikuti Program Online yang mempunyai penyelenggara dan reviewer asatidz.

Alur utama: **belajar → menyimak → latihan → setoran → koreksi → perbaikan/verifikasi → penjagaan**. Setoran audio/teks adalah objek terpisah dari jurnal self-record. Hanya bukti yang dikirim ke program yang dapat dilihat reviewer berwenang.

Program dapat berbentuk Tahfizh, Tahsin, membaca Al-Qur’an, atau Murāja‘ah dengan mode online/offline/hybrid. Program juga dapat dikaitkan ke satu program Academy sehingga peserta Personal memperoleh materi pendukung tanpa membuka seluruh konten lintas lembaga.

Verifier produksi: `php artisan sullam:verify-guided-quran`.
