# v2.1.0 — Unified Platform & Secure Media

## Perubahan utama

- Menambahkan fondasi database: cabang, periode akademik, pusat media, target pengumuman, target Pembinaan Jumat, histori marhalah, undangan akun, dan feature flag.
- Menutup caching respons privat pada service worker.
- Mengamankan unggahan dengan tipe file terbatas, nama acak, checksum, visibility, retention, dan controller permission.
- Membatasi website/admin/content berdasarkan `institution_id`.
- Menambahkan permission middleware, reset password, aktivasi akun, audit akses media privat, dan trusted proxy terbatas.
- Menyesuaikan navigasi mobile guru, wali dan admin dengan wireframe terbaru.
- Mengimplementasikan icon system solid-organic emerald–gold.
- Menambahkan panel **Fondasi Platform** sehingga modul, cabang, dan periode dapat diatur tanpa redeploy.
- Menjaga Audio Qur’an, Academy/LMS, rapor, website, dan pendaftaran sebagai pengembangan bernilai yang dapat dikendalikan melalui feature flag.
- Menambahkan API starter dan penanganan staging `noindex`.

## Kompatibilitas

Migration bersifat additive. Kolom legacy seperti `file_path`, `attachment_path`, dan `worksheet_path` tetap dibaca agar data lama tidak hilang. Upload baru memakai `media_assets`.
