# v4.4.3 — Blade Directive Structure Hotfix

`@phase 4.4.3`

Rilis ini memperbaiki kegagalan GitHub Actions `Tests #60` setelah v4.4.2.

## Perbaikan

- Directive `@foreach`, `@if`, `@csrf`, `@method`, dan penutupnya pada halaman komunikasi dipisahkan menjadi blok yang eksplisit.
- Pembentukan label variabel template dipindahkan ke blok `@php ... @endphp` yang tidak bersarang dengan directive lain.
- Blok filter status, status error pengiriman, dan aksi retry ditata ulang agar hasil kompilasi PHP seimbang.

## Dampak

- Tidak ada migration baru.
- Tidak ada perubahan data pengguna, lembaga, media, kredensial, atau environment.
- Seluruh fungsi komunikasi v4.1.0 serta fondasi v4.4.0 tetap dipertahankan.

## Gate

Redeploy Coolify hanya dilakukan setelah `php-tests`, `docker-build`, dan `release-docs` lulus.
