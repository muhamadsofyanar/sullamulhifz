# v4.4.2 — Blade Compilation & Release Docs Hotfix

`@phase 4.4.2`

Rilis ini memperbaiki kegagalan GitHub Actions setelah v4.4.1.

## Perbaikan

- Daftar variabel template komunikasi dibentuk sebagai nilai PHP terlebih dahulu, lalu ditampilkan melalui satu ekspresi Blade yang aman.
- Tidak ada lagi directive `@foreach` bertingkat dalam satu baris yang menghasilkan `unexpected token "endforeach"`.
- Dokumen `UPGRADE`, catatan rilis, versi publik, dan indeks rilis diselaraskan ke v4.4.2.

## Dampak

- Tidak ada migration baru.
- Tidak ada perubahan data pengguna, lembaga, media, atau kredensial.
- Seluruh fitur v4.4.0 tetap dipertahankan.

## Gate

Redeploy Coolify hanya dilakukan setelah `php-tests`, `docker-build`, dan `release-docs` lulus.
