# v3.3.0 — Personal Program Hub

Tanggal kandidat: 9 Agustus 2026.

Rilis ini menjadikan Ruang Personal sebagai shell privat yang dapat menampung banyak jalur belajar tanpa menganggap Audio sebagai satu-satunya program. Jurnal, target, dan catatan aktivitas tetap tersedia sebagai fondasi akun; modul belajar hanya tampil ketika enrollment terkait aktif.

Modul yang didukung pada rilis ini:

- Latihan Qur’an;
- Qur’an Journey;
- Program dengan Asatidz / Guided Quran;
- Academy yang diturunkan dari Guided Quran enrollment terhubung.

Migration `002400` hanya menambah tabel enrollment modul dan membackfill akses dari histori nyata. Tidak ada penghapusan data lama.
