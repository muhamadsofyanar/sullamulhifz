# v3.4.0 — Personal Enrollment Lifecycle

Tanggal kandidat: 9 Agustus 2026.

Rilis ini menyelesaikan penyelarasan pengalaman Personal. Pengguna dapat memilih modul saat mendaftar, mengubahnya dari Program Saya, dan melihat Home serta navigasi yang hanya berisi program aktif.

Jurnal, target, dan histori tidak dihapus ketika sebuah modul dinonaktifkan. Status enrollment eksplisit tetap menjadi keputusan akses, sehingga histori lama tidak membuka kembali modul tersebut. Program yang masih mempunyai enrollment Guided Quran atau Qur’an Journey aktif tidak dapat disembunyikan sampai enrollment programnya berakhir. Academy tetap hanya hadir dari program yang terhubung.

Rilis ini tidak menambah migration database.
