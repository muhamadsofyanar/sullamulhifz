# Release v1.4.3 — Ikrar Santri

Tanggal paket: 6 Agustus 2026.

## Ringkasan

Rilis ini mengeksplorasi materi Ikrar Santri TPA Al-Insyirah menjadi fitur website dan portal yang responsif, dapat dicetak, serta dapat diperbarui admin.

## Perubahan

- route publik `/ikrar-santri`;
- route portal `/nilai/ikrar-santri`;
- route admin `/admin/ikrar-santri`;
- konfigurasi default `config/student_pledge.php`;
- penyimpanan kustom melalui `system_settings`;
- integrasi homepage, halaman TPA, footer, dan sidebar;
- CSS responsif dan cetak;
- pengujian fitur.

## Database

Tidak ada migration baru. Editor admin memanfaatkan tabel `system_settings` dari migration v1.4.0. Halaman publik dan portal tetap dapat dibuka dengan data default apabila tabel tersebut belum tersedia.

## Risiko

- Editor admin tidak dapat menyimpan sebelum migration v1.4.0 telah dijalankan.
- Konten perlu ditinjau lembaga sebelum diumumkan sebagai versi resmi.
- Mode cetak perlu diuji pada browser yang digunakan lembaga.
