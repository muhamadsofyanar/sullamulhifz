# v4.9.0 — Ruang Belajar Terpadu

`@phase 4.9`

Rilis ini menjalankan Fase 8 Product Expansion Track: **Learning & Academy Integration**. Fase ini tidak membuat mesin pembelajaran baru; ia menyatukan mesin yang sudah matang ke satu pengalaman Personal sambil mempertahankan sumber data, ownership, consent, dan isolasi workspace.

## Yang berubah untuk Personal

- menu baru **Ruang Belajar**;
- Beranda Personal mengarahkan tombol utama ke Ruang Belajar;
- program aktif tetap dapat dibuka langsung seperti sebelumnya;
- ringkasan 30 hari Latihan Qur’an;
- daftar Qur’an Journey aktif;
- daftar Program Asatidz dan status setoran terakhir;
- ringkasan Academy yang terhubung;
- target Personal, arahan Ustadz Privat, dan tugas lembaga diringkas dalam konteks yang sama;
- langkah berikutnya disusun dari data yang sudah tersedia bagi akun tersebut.

## Guardrail

- tidak ada salinan jurnal Personal ke tabel baru;
- isi portofolio tidak ikut diringkas;
- rekomendasi Academy hanya muncul jika akses Academy aktif;
- sesi Ustadz hanya muncul untuk learner pemilik akun dan relasi `mentor_learner` yang masih accepted;
- tugas lembaga hanya dibaca dari workspace dengan membership aktif;
- tidak ada ranking peserta, ranking cita-cita, atau scoring lintas pengguna.

## Database

Tidak ada migration baru. Semua integrasi membaca tabel yang sudah tersedia dari release sebelumnya.

## Release gate

- syntax PHP untuk file v4.9.0 wajib lulus;
- `python3 scripts/check-phase-manifest.py` wajib lulus;
- PHPUnit/Blade/Docker build wajib hijau di GitHub Actions;
- `php artisan sullam:verify-learning-hub-v490` wajib PASS di produksi;
- smoke test dua akun Personal wajib memastikan tidak ada target/data privat yang bercampur.
