# Sullamul Ḥifẓ v1.4.2 — Academic Foundation Examples

Paket ini berisi **contoh data, alur, dan spesifikasi** untuk mematangkan fondasi akademik Sullamul Ḥifẓ sebelum dikembangkan menjadi fitur aplikasi.

Paket ini **bukan source upgrade** dan tidak mengubah database. Tidak perlu redeploy, migration, seeder, atau `db:wipe`.

## Isi

- Profil lembaga contoh
- Struktur Tahun Ajaran 2026/2027
- Struktur kelas dan penugasan guru TPA Al-Insyirah
- Sistem Tahfizh Juz 30 berbasis 8 rubu'
- Kerangka marhalah
- Kerangka STIFIn yang aman
- Model Community dan Pembinaan Jumat
- User flow admin, guru, dan wali
- Data dictionary konseptual
- Spesifikasi calon rilis v1.4.2
- Contoh data JSON tanpa data pribadi anak

## Prinsip utama

1. Aplikasi mencatat dan menghubungkan, bukan menggantikan talaqqi, keteladanan, pembiasaan, interaksi keluarga, dan pembinaan nyata.
2. Tidak ada ranking santri.
3. Rubu' adalah milestone perjalanan, bukan label kemampuan atau marhalah.
4. STIFIn hanya informasi tambahan dan tidak menentukan kelas, marhalah, atau nilai santri.
5. Data anak, akun, email, nomor WhatsApp, dan password tidak boleh dimasukkan ke repository publik.
